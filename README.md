# Restaurant Operations Manager

A Java OOP desktop application that models restaurant operations through a Swing interface. The project separates domain models, GUI components, persistence utilities, and custom exceptions.

## Highlights

- Manage menu items, orders, chefs, and kitchen state
- Track sales and operational data
- Model food categories through inheritance and polymorphism
- Validate workflows with custom exceptions
- Persist application data locally

## OOP design

The codebase demonstrates encapsulation, inheritance, polymorphism, interfaces, exception handling, and separation of concerns across `model`, `gui`, `util`, and `exception` packages.

## Run

Compile the Java files under `src` and run `Main`. A Java IDE such as IntelliJ IDEA or Eclipse can import the repository as a source-based project.
